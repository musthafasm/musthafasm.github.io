About me

A little more about me

I'm a developer passionate about building for the web, with over two decades of experience. I believe good development goes beyond simply making things work. It's about writing clean, well-structured code that's easy to maintain, extend, and evolve.

With a strong focus on WordPress development, I create custom plugins, tailored functionality, and polished interfaces that go beyond the limitations of ready-made solutions.

I'm equally focused on website performance and search visibility. I audit existing websites, resolve technical SEO issues, improve page speed and Core Web Vitals, and refine the underlying code and structure so websites load faster and rank better in search.

Outside of client projects, I enjoy exploring programming languages, studying software architecture, experimenting with emerging technologies, and discovering better ways to build software.
