# Musthafa Sali Maheen

Personal portfolio website showcasing my work, experience, skills, and services as a Creative Web Developer & SEO Specialist.

## Development Environment

This project uses [Vite](https://vite.dev/) as its development server and build tool.

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)

### Installation

Clone the repository:

    git clone https://github.com/your-username/your-repository.git

Navigate to the project directory:

    cd your-repository

Install dependencies:

    npm install

### Development

Start the local development server:

    npm run dev

Vite will provide a local development URL, usually:

    http://localhost:5173

### Production Build

Generate an optimised production build:

    npm run build

The production-ready files will be generated in the `dist/` directory.

### Preview Production Build

Preview the production build locally:

    npm run preview
